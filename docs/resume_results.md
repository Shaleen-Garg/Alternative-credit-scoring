# Resume-ready results

- Built a reproducible alternative-credit-risk pipeline using SQLite and Python to aggregate application, bureau, prior-loan, and installment-payment data for 307,511 Home Credit applicants.
- Designed a frozen-split A/B/C feature-group ablation and nonlinear robustness evaluation; adding behavioural history improved HGB ROC-AUC/PR-AUC by 0.0089/0.0124 overall and 0.0197/0.0371 among borrowers with no bureau record.
- Added validation-only sigmoid calibration, illustrative cost and approval analyses, model-reliance explanations, and cohort/stability diagnostics with leakage and reproducibility audits.

Use “historical Home Credit dataset” and “random holdout” when discussing these results. Do not describe them as production impact, fairness validation, causal effects, or out-of-time performance.
